# RocketMovies

RocketMovies é um site de avaliação de filmes que permite ao usuário adicionar filmes e avalia-los como tambem ver e pesquisar pela avaliação de outras pessoas.

## Páginas

### Home

-Onde o usuário podera visualizar suas avaliações e a de outros

### Preview

-Página de preview de uma avaliação com a descrição feita pelo usuario, nome, categoria, estrelas e etc.

### User

-Página de visualização das informações do perfil, onde o usuário podera atualizar e ver suas informações,são elas, foto de perfil, nome, email e senha.

### CreateMovie

-Página para criação de avaliação com inputs de nome, categoria, desrição, estrelas e etc.

## Como executar o projeto

Clone o repositório:

```bash
git clone https://github.com/Toddynh0BR/Rocket-Movies-Front.git
```

Acesse o diretório do projeto:

```bash
cd RocketMovies
```
Instale as dependências:
```bash
npm install
```
Inicie o servidor de desenvolvimento:
```bash
npm start
```
Sinta-se à vontade para contribuir com o projeto.
